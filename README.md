# Daily Expense Tracker

## About
Daily Expense Tracker is a web application that helps users calculate and manage their daily income and expenses.

## Features
- Calculate total income
- Calculate total expenses
- Calculate remaining balance
- Add transactions
- Edit and delete transactions
- Set monthly budget
- Search expenses
- View expense charts
- Save data using Local Storage

## Technologies Used
- HTML
- CSS
- JavaScript
- Chart.js

## Purpose
To help users track daily spending and manage money efficiently.
